# Sidequest

Use Node.js 22+. This is a dependency-free static site, hosted on GitHub Pages.
Keep public content in `site/`. Never introduce Jekyll or absolute asset paths.
Register pages and dashboards in `site/catalog.json`; prefer the `npm run new` generator.
Label demo data clearly. Do not commit secrets or private source data.
Run `npm run build` after changes. Preserve keyboard access and responsive layouts.
